# Specs

Living plan/spec documents for features under active or upcoming work. One folder
per feature: `specs/<feature-name>/`.

`agent/` holds the durable **constitution**; `specs/` holds **working plans** for
specific features. When a feature ships, its spec stays as a historical record (or is
archived).

> **The process, file set, naming, and conventions for specs live in the
> `spec-process` skill:** [`.cursor/skills/spec-process/SKILL.md`](../.cursor/skills/spec-process/SKILL.md).
> Read that first. New specs can be scaffolded with
> `.cursor/skills/spec-process/scripts/scaffold.sh <block>-<feature-slug>`.
