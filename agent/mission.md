# Mission

## What Greenroom Hunter Is
Greenroom Hunter is a marine surf data application, built primarily for surfers. It makes live marine data — starting with buoy readings — more accessible and region-specific, so surfers can use real data to decide where the best place to surf is.

## Who It's For
Surfers who want to make data-driven decisions about where and when to surf. Today the coverage is Southern California, with the goal of expanding to anywhere in the USA that has live data readings. It's a niche tool, and that's by design — it doesn't need to appeal to everyone.

## Why It Exists
1. **A tool I actually use.** Above all, this is something I want to reach for every day. The user (me) is the first customer.
2. **A code demo and playground.** This is a project for experimenting with new technologies. It happens to also be a genuinely useful tool, but the freedom to try new tech is a core reason it exists.

The current focus is making buoy data more accessible and region-specific. Over time, the vision is to add more features and tools that help surfers read conditions and pick the best spot.

## What Success Looks Like
- A tool that works **seamlessly** and has a **great user experience**.
- Something I want to use every day, that a small circle of friends also find valuable.
- A codebase that stays a comfortable place to experiment with new technology.

Success is *not* measured by mass adoption. A small, happy user base — including myself — is the point.

## Guiding Principles
- **Seamless experience first.** Reliability and a clean, fast UX matter more than feature count.
- **Data-driven and accessible.** Surface the right data, region-specific, in a form surfers can actually act on.
- **Freedom to experiment.** This is a place to try new tech; embrace that while keeping the live tool stable.
- **Purpose may evolve.** This mission reflects the project's current intent and is expected to change as it grows.
