# Spec Process

The spec process now lives as a Cursor skill so it loads automatically when planning
a feature and can scaffold the spec files for you:

**[`.cursor/skills/spec-process/SKILL.md`](../.cursor/skills/spec-process/SKILL.md)**

It's the single source of truth for spec naming, the standard file set, the steps, and
spec-writing conventions. Feature specs themselves live in [`specs/`](../specs/README.md).
